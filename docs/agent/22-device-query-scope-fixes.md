# 实机查询验收补修：时间范围、展示与取消目标

开发者工具的合成账户验收发现三个缺口：开放的上周查询按最新训练日期倒推时间；上周正文显示3次训练但卡片显示两周合计4次；取消动作比较后，否定句中的“动作”仍使固定统计报告被排除。

## 修改

- 日历周历史查询按服务器当前日期和Asia/Shanghai时区生成起止日期。workout.list_history新增成对start_date/end_date参数，按用户、完成/提前结束状态及日期过滤后再取最多20条。返回范围内总数、展示条数及截断标记；超过20条不声称列出了全部记录。旧最近N次调用仍可省略日期。
- 周统计使用同一范围投影生成正文与卡片；原始ToolMessage与审计保留实际查询返回值。卡片标注范围，历史卡片说明部分展示。
- 仅去除完整的、明确取消动作比较的独立语句片段；保留真实动作比较、建议、明细和复合请求，不擅自扩展工具权限。

## 验证

新增回归覆盖旧代码失败的原句、上周/上上周/明确区间/空周卡片一致性、缺失和非法日期、日期过滤先于截断、超过10/20条、用户隔离、真实多目标保护、卡片持久化与原始审计分离。

PostgreSQL定向169项通过；本地首次全量1225项通过、4项旧模拟工具签名不兼容新增可选参数，已同步签名并通过上述定向回归，原断言保留。小程序类型检查及265项构建契约通过。

真实模型+本地API复跑7次，包含原上周题两次、连续追问、取消任务和动作比较；7条保存结果均通过数字、日期及适用的卡片检查。执行阶段为固定报告，不调用自由回答模型；意图理解仍调用模型。

这不等于修复后实机界面已经复验。正式待澄清状态切换、任意取消表述、所有自然语言查询及线上负载不在上述通过结论内；原实机失败记录继续保留，不覆盖旧回答。
